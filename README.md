# Snake Game

A classic Snake game implemented using Python and Pygame library, where the player controls a snake to eat food and grow, avoiding collisions with walls or itself.

## Features

*   Player-controlled snake movement (Up, Down, Left, Right)
*   Food generation at random positions
*   Snake growth upon eating food
*   Score tracking
*   Game over conditions (collision with walls or self)
*   Basic graphical interface

## Tech Stack

*   Python
*   Pygame

## Installation

To get started, first ensure you have Python installed. Then, install the required Pygame library using pip:

```bash
pip install -r requirements.txt
```

## How to Run

After installing the dependencies, you can run the game from your terminal:

```bash
python snake_game.py
```

## Controls

Use the arrow keys to control the snake's movement:

*   **Up Arrow Key:** Move up
*   **Down Arrow Key:** Move down
*   **Left Arrow Key:** Move left
*   **Right Arrow Key:** Move right
